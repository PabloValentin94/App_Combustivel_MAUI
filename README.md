# Aplicativo de Comparação de Combustíveis

O objetivo desse aplicativo é fazer uma comparação matemática entre o preço e o rendimento de etanol e gasolina.

## Explicação

No cenário abordado, o etanol tem um rendimento equivalente a 70% do da gasolina. Exemplo:

| Combustível | Rendimento | Distância (KM/L) |
| :- | :- | :- |
| Gasolina | 100% | 10 Quilômetros (KM) |
| Etanol | 70% | 07 Quilômetros (KM) |

## Classificações

Com base no processamento do aplicativo, é possível determinar qual deles é mais econômico com base no preço por litro especificado de cada um. Veja a seguir as possibilidades:

| Análise | Resultado |
| :- | :- |
| O preço do etanol é igual a 70% do preço da gasolina. | A escolha é indiferente. |
| O preço do etanol é maior que 70% do preço da gasolina. | A gasolina é mais econômica. |
| O preço do etanol é menor que 70% do preço da gasolina. | O etanol é mais econômico. |
